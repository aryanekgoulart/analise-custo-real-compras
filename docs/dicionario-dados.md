# Dicionário de dados do resultado

| Campo | Descrição |
|---|---|
| `NUNOTA` | Identificador da nota fiscal |
| `CODEMP` | Empresa responsável pela compra |
| `DTNEG` | Data de negociação |
| `DTENTSAI` | Data de entrada da nota |
| `CODPARC` | Identificador do fornecedor |
| `RAZAOSOCIAL` | Nome empresarial do fornecedor |
| `CODPROD` | Identificador do produto |
| `DESCRPROD` | Descrição do produto |
| `QTDNEG` | Quantidade negociada |
| `VLRUNIT` | Valor unitário informado na compra |
| `VLR_PROD` | Base agregada utilizada na distribuição dos custos |
| `VLR_CLICHE_UN` | Custo adicional dividido pela quantidade |
| `ICMS` | Ajuste unitário de ICMS conforme a regra da empresa |
| `IPI` | IPI calculado por unidade |
| `SIMPLES` | Ajuste unitário relacionado ao Simples Nacional |
| `ST` | Substituição tributária transformada em valor unitário |
| `FRETE_FINAL` | Parcela unitária de frete aplicada ao item |
| `CUSTO_UNITARIO_FINAL` | Soma dos componentes do custo unitário |
| `CUSTO_UNITARIO_ANTERIOR` | Custo da compra anterior do mesmo produto |
| `VARIACAO_VALOR` | Diferença entre o custo atual e o anterior |
| `VARIACAO_PERCENTUAL` | Variação percentual em relação ao custo anterior |
